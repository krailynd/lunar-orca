# Glosario

| Término | Definición |
|---|---|
| Lunar Orca | Fork personalizado de Orca usado como entorno de agentes. |
| LunarGrip | Módulo de datos propuesto para Lunar Orca. |
| LunarMind | Nombre propuesto para la asistencia de IA contextual al esquema. |
| Arnés PI | Entorno que coordina agentes, tareas, mensajes y lifecycle. |
| Snapshot | Fotografía estructural de un esquema en un contrato versionado. |
| Layout | Posición, filtros, colores y notas de un diagrama. |
| Introspección | Lectura de metadatos para conocer objetos y relaciones. |
| Object Explorer | Árbol navegable de servidores, bases y objetos. |
| Vecindario | Subgrafo alrededor de una tabla u objeto seleccionado. |
| Preview | Vista previa de una acción antes de ejecutarla. |
| Mutación | Operación que cambia datos, esquema, permisos o estado. |
| Host | Máquina donde se ejecuta una operación: local o remota. |
| Evidencia | Dato verificable que respalda un hecho o resultado. |
